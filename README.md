# Linux Bash Workshop

A beginner-friendly hands-on workshop to learn the basics of Linux and the command line.

## Overview

This workshop introduces essential Linux skills through practical exercises.  
You will learn how to navigate the file system, work with files, search for data, and combine commands effectively.

No prior experience is required.

## 🧠 What You’ll Learn

- Navigate directories using the terminal
- View and create files
- Search for text using `grep`
- Combine commands using pipes (`|`)
- Save output using redirection (`>`, `>>`)
