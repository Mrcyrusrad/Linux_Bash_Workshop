# Exercise 3: Searching with grep

## Goal
Learn how to search for text in files.

## Tasks

1. Find all lines containing "apple" in `fruits.txt`
2. Find all lines containing "ERROR" in `log.txt`
3. Count how many lines contain "ERROR"
4. Find the line above and below "INFO" in `log.txt`
4. Find all lines containing "INFO"
5. Count how many times "banana" appears in `fruits.txt`

## Bonus
Try searching for a word that does NOT exist

## Hints
Use grep "word" filename to search for matching lines.
Use grep -c "word" filename to count matching lines.
