# Exercise 1: Navigation Basics

## Goal
Learn how to move around the file system.

## Tasks

1. Print your current directory
2. List all files and folders
3. Navigate into the `practice` folder
4. Create a new folder called `test`
5. Go into the `test` folder
6. Go back to the parent directory
7. Delete the `test` folder

## Bonus
Try using `ls -l` to see more details
