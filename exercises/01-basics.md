# Exercise 1: Navigation Basics

## Goal
Learn how to move around the file system.

## Tasks

1. Print your current directory
2. List all files and folders
3. List all including hidden and show size
4. Navigate into the `practice` folder
5. Create a new folder called `test`
6. Go into the `test` folder
7. Go back to the parent directory
8. Delete the `test` folder

## Bonus
Try using `ls -l` to see more details
