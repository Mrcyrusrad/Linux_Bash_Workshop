# Exercise 2: Working with Files

## Goal
Learn how to view and create files.

## Tasks

1. Navigate into the `practice` folder
2. Print the contents of `fruits.txt`
3. Print the contents of `log.txt`
4. Show only the first 3 lines of `log.txt`
5. Show only the last 2 lines of `log.txt`
6. Create a new file called `notes.txt`
7. Add some text into `notes.txt` using echo

## Bonus
Try opening a file using `less`

## Hints
Use head -n 3 filename for the first 3 lines.
Use touch filename to create a new empty file.
Use echo "your text here" > filename to write text into a file.
